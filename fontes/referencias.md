# Referências

## Modelo estratégico dinâmico

- OWASP FOUNDATION. **API6:2023 — Unrestricted Access to Sensitive Business Flows**. OWASP API Security Top 10, 2023. Disponível em: <https://api-security.owasp.org/editions/2023/en/0xa6-unrestricted-access-to-sensitive-business-flows/>. Acesso em: 3 out. 2026. Fundamenta o recorte de abuso do fluxo de reservas e a relação entre controle de acesso e disponibilidade de horários.
- OWASP FOUNDATION. **OWASP Automated Threats to Web Applications**. Disponível em: <https://owasp.org/projects/automated-threats-to-web-applications>. Acesso em: 3 out. 2026. Fundamenta a análise de abuso automatizado de funcionalidades válidas, sem pressupor uma falha técnica já comprovada.
- CODEFÓLIO. **Trabalho 1 — Análise de um Sistema Adversarial: modelo estático, modelo dinâmico, ameaças e riscos**. Enunciado da disciplina. Disponível em: <https://codefolio.com.br/classes?courseId=-P-1Q_SRUut99WFCh8Bj>. Acesso em: 3 out. 2026. Define os requisitos de modelagem das rodadas, observação, adaptação, custos e diagramas.
- CODEFÓLIO. **Aula 6 — Apresentação do Enunciado do Trabalho**. YouTube. Disponível em: <https://www.youtube.com/watch?v=0HotE0OZ3FY>. Acesso em: 3 out. 2026. Trechos sobre o modelo dinâmico e o ciclo adaptativo: 25min33s a 29min18s.
